# Русификатор The Letter - Horror Visual Novel

[Игра](https://store.steampowered.com/app/460430/The_Letter_Horror_Visual_Novel/) уже имеет частичный русский перевод, но он ужасного качества и охватывает только 1 и 2 главу.

Прогнал по готовому тексту сверку и добил оставшиеся 60%. Перевод, очевидно, машинный, в игре слишком много текста для ручного, но откровенного бреда и белиберды быть не должно. Установка: кинуть в папку с игрой и запустить батник
 

Для актуальной версии 2.3.3:

[`The Letter 2.3.3 русификатор.zip`](The%20Letter%202.3.3%20%D1%80%D1%83%D1%81%D0%B8%D1%84%D0%B8%D0%BA%D0%B0%D1%82%D0%BE%D1%80.zip)

Для версии 1.1.9:

[`The Letter русификатор.zip`](https://github.com/KoinEZ/the-letter-horror-visual-novel/releases/download/the-letter-horror-visual-novel/The.Letter.zip)
После запуска игра записывает файлы локализации в кэш "...\AppData\LocalLow\Yangyang Mobile\The Letter\" поэтому добавлен батник "Установить", который чистит эту папку. Короче, если есть проблемы после запуска - попробуйте запустить очистку и проверить есть ли в настройках языка "русский", с маленькой буквы без всяких (BETA) - только тогда он работает
